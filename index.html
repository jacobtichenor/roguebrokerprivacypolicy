Rogue Broker

A roguelike trading simulator for iPhone.

You are an intergalactic merchant on the wrong side of a loan shark, the Broker. Miss a payment and the run ends; level up at the end of each run to make it further in the next.

Support

Questions, bugs and feedback all go to one place:

  • roguebrokergame@gmail.com

If you are reporting a bug, the two things that help most are what you were doing when it happened and what you expected instead. Easier still: use Report a bug in Settings, which writes the email for you and attaches the details of the run you were playing. You can read and edit all of it before it sends.

Common questions

Where is my progress stored? On your device, in the app's own storage. Data Cores, captains, ranks, upgrades, achievements and run history are all in a save file that goes away when the app does. With iCloud sync on it also syncs to your own private iCloud, which the developer cannot read.

Can I turn the sound or haptics off? Yes, both, in Settings from the main menu. The same screen has eight colour schemes, and one of them is a light theme.

Is there any advertising or tracking? No. No ads, no analytics service, no third-party SDKs of any kind, and nothing that follows you anywhere. There is one switch, Share run data, which is on during the closed beta and can be turned off at any time. With it on, the game sends an anonymous record of how each run went: the net-worth curve, what you bought, how it ended. That is what the difficulty gets tuned against. No name, no email, no identifiers, nothing you typed. The privacy policy lists every field, and you can turn it off at any time, which deletes what it has kept.

Privacy

Privacy policy. The only data this game collects and sends to the developer is your run data to help with difficulty tuning. You control both the collection and sharing of this data by opting out in the settings. No personal data whatsoever is collected, stored, or shared.
